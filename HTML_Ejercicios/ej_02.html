Desarrollo de Aplicaciones Web

En este ciclo formativo aprenderemos diferentes tecnologías relacionadas con el desarrollo de aplicaciones web.

Lenguajes de marcas

Los lenguajes de marcas permiten estructurar y organizar la información de los documentos.

HTML

HTML es el lenguaje utilizado para crear la estructura de las páginas web.

CSS

CSS permite definir la presentación y el aspecto visual de una página web.

JavaScript

JavaScript permite añadir comportamiento e interactividad a las páginas web.

Conclusión

Estas tecnologías son fundamentales para el desarrollo web.
