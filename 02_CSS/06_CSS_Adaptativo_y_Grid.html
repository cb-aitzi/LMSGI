Diseño web adaptativo

  • Intenta que las páginas se vean bien en todos los dispositivos.
  • Con CSS y HTML se cambia el tamaño, se oculta, se reduce, se amplía o se mueve el contenido según la pantalla.
  • Gracias a ello no hace falta una web distinta para cada tipo de dispositivo.
  • Normalmente se diseña primero para móvil (donde hay más limitaciones de espacio y recursos) y luego se añaden reglas para pantallas mayores.

Buenas prácticas

  • No usar tablas para maquetar.
  • Usar preferentemente unidades relativas (%, em, rem, vw, fr): se adaptan al dispositivo; las absolutas son fijas.
  • Imágenes flexibles: max-width: 100%; height: auto;
  • Maquetar con Flexbox o Grid.

En inglés se llama responsive web design. Es lo habitual hoy: más de la mitad del tráfico web viene de móviles.

El primer paso: la etiqueta viewport

  • width=device-width: el ancho de la página es el ancho real del dispositivo.
  • initial-scale=1.0: escala inicial 1; la página se muestra a su tamaño original, sin zoom.

Sin esta etiqueta, los móviles fingen tener una pantalla de unos 980 px y reducen la página: las media queries no funcionarían como esperas.

@media: reglas que dependen de la pantalla

Una media query define un conjunto de reglas que solo se aplican si se cumple una condición (tipo de medio, ancho, orientación...).

Si la información se muestra en pantalla y mide hasta 500 px de ancho, header, nav y footer miden 50 px de alto y el 100 % de ancho.

Estrategia «móvil primero» (mobile first)

Escribes primero el CSS para el móvil (sin media query) y vas añadiendo reglas para pantallas mayores con min-width.

  • El móvil carga menos CSS.
  • Las reglas crecen de forma ordenada: de pequeño a grande.
  • Con max-width (de grande a pequeño) acabas deshaciendo reglas.

Puntos de ruptura (breakpoints) de ejemplo

640pxmóviles (vertical u horizontal) y tabletas pequeñas

1800pxpantallas muy grandes

Con tantos tamaños de pantalla, no hay medidas universales. Lo mejor es poner el breakpoint donde tu diseño empieza a verse mal.

Sección 2

Grid layout

Una rejilla de filas y columnas para maquetar en dos dimensiones.

¿Qué es CSS Grid?

Es una técnica que permite crear diseños complejos con mayor facilidad. Es el último paso en la evolución de la maquetación: tablas, modelo de cajas, Flexbox y ahora Grid.

Que sea lo más reciente no significa que sustituya a Flexbox: ambos tienen su sitio en el diseño web actual.

Fundamentos de Grid

Un diseño Grid tiene un elemento principal (contenedor) y uno o más elementos de segundo nivel (ítems).

Todos los hijos directos del contenedor pasan a ser ítems.

grid es un elemento de bloque: empieza en una línea nueva y ocupa todo el ancho. inline-grid es en línea: solo ocupa lo que necesita.

Filas, columnas, huecos y líneas

  • Filas y columnas.
  • Huecos (gap) entre filas y entre columnas.
  • Líneas: las divisiones (rojas), numeradas desde 1. Con n columnas hay n+1 líneas.

Las líneas sirven para colocar ítems: «de la línea 1 a la 3» en grid-column o grid-row.

Laboratorio: definir filas y columnas

grid-template-columns y grid-template-rows definen cuántas filas y columnas hay y qué tamaño tienen. Escribe tu propio valor o elige uno.

Colocar elementos en el grid

Un ítem se puede colocar eligiendo las líneas donde empieza y acaba: grid-column: inicio / fin y grid-row: inicio / fin (o con span: «ocupa 2»).

El ítem rojo («A») se coloca donde le dices; los demás se reparten automáticamente por los huecos libres. Si inicio ≥ fin, el navegador lo corrige.

Zonas con nombre: grid-template-areas

Dibujas el diseño con palabras. El contenedor define las zonas (grid-template-areas) y cada ítem dice a cuál pertenece (grid-area).

Para el móvil basta con redefinir las áreas dentro de una media query: el HTML no cambia.

Galería adaptativa sin media queries

Cuando no queremos fijar el número exacto de columnas, sino que dependa del dispositivo, Grid lo resuelve con repeat(auto-fit, minmax(...)): «tantas columnas de al menos X como quepan».

Sin ninguna media query, el número de columnas se adapta solo. auto-fit estira las columnas para ocupar todo el ancho; auto-fill conserva columnas vacías.

¿Flexbox o Grid?

FlexboxGrid
DimensionesUna (fila o columna)Dos (filas y columnas)
Parte de...el contenido: los ítems deciden cuánto espacio necesitanla rejilla: primero se dibuja, luego se coloca el contenido
Ideal paramenús, barras de herramientas, tarjetas en fila, centraresqueleto completo de la página, galerías, paneles
Solaparno es lo normallos ítems pueden ocupar las mismas celdas

No son rivales: lo habitual es usar Grid para el esqueleto de la página y Flexbox dentro de los componentes (un menú, una tarjeta). Un ítem de Grid puede ser, además, un contenedor flex.

Novedad: subgrid permite que una rejilla anidada herede las líneas de la rejilla padre. Ya funciona en los navegadores actuales (grid-template-columns: subgrid); no es un valor de display.

Resumen

Adaptativo

La página se ve bien en cualquier pantalla: unidades relativas, imágenes flexibles y Flexbox/Grid.

viewport

<meta name="viewport" content="width=device-width, initial-scale=1.0"> es imprescindible.

@media

Reglas condicionadas al ancho, la orientación o el medio. Móvil primero con min-width.

Grid

display: grid, grid-template-columns/rows, gap, fr y repeat().

Colocar

Líneas con grid-column/grid-row o zonas con grid-template-areas y grid-area.

Galería

repeat(auto-fit, minmax(X, 1fr)) adapta el nº de columnas sin media queries.

Autoevaluación: ¿lo tienes claro?

Contesta mentalmente y luego despliega cada pregunta.

1. ¿Para qué sirve la etiqueta viewport?

Para que el ancho de la página sea el del dispositivo, con escala inicial 1; sin ella los móviles reducen la página y las media queries no se comportan como esperas.

2. ¿Qué diferencia hay entre diseñar «móvil primero» y «escritorio primero»?

Móvil primero: reglas base para móvil y min-width para ampliar. Escritorio primero: reglas base de escritorio y max-width para recortar.

3. ¿Cómo escribes «pantalla de menos de 500 px o en horizontal»?

@media (max-width: 500px), (orientation: landscape) { ... } (la coma hace de «o»).

4. ¿Qué significa 1fr 2fr en grid-template-columns?

Dos columnas que se reparten el espacio libre en proporción 1:2.

5. ¿Qué hace grid-column: 1 / 3?

El ítem empieza en la línea 1 y acaba en la 3, es decir, ocupa dos columnas.

6. ¿Cuándo prefieres Flexbox y cuándo Grid?

Flexbox para una dimensión (menús, filas de tarjetas); Grid para dos dimensiones (esqueleto de página, galerías).
