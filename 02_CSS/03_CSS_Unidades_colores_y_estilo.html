Sección 1

Unidades y colores

Cómo decirle a CSS «cuánto» y «de qué color».

Medidas absolutas y relativas

Absolutas: no dependen de nada. 300px siempre son 300 píxeles. Pero 12 px pueden bastar en un móvil y ser casi ilegibles en una pantalla de alta resolución.

Relativas: dependen de otra cosa: el tamaño de la letra, el contenedor o la ventana. Se adaptan a cada dispositivo (diseño adaptable o responsive), aunque no sabemos con exactitud cuánto mide cada cosa.

Arrastra el control: la barra de 50% se adapta al contenedor y la de 300px no.

Regla práctica: píxeles y % para el diseño (anchos de columnas y elementos); em y % para el tamaño de letra. Hoy se recomienda también rem para el texto: respeta el tamaño de letra que el usuario haya elegido en su navegador.

Imágenes: dale un width en unidad relativa (como 50%) y el height se ajusta solo, sin deformar la imagen.

Cuatro formas de indicar un color

Mismo color, distintas notaciones: el rojo puro se puede escribir así:

FormatoCómo se escribeNotas
NombreredColores conocidos: white, silver, gray, black, maroon, olive, lime, teal, navy, purple... y muchos más.
Hexadecimal#FF0000 · abreviado #F00El más usado. # + 6 cifras: RR GG BB (rojo, verde, azul).
RGB / RGBArgb(255, 0, 0) · rgba(255, 0, 0, 0.5)Cada componente de 0 a 255 (o en %). El cuarto valor, alpha, es la transparencia: 0 = invisible, 1 = opaco.
HSL / HSLAhsl(0, 100%, 50%) · hsla(0, 100%, 50%, 0.5)Tono, saturación y luminosidad. El más cercano a cómo percibimos los colores.

RGB: mezclar luz roja, verde y azul

Cada color de pantalla es una mezcla de rojo, verde y azul, de 0 (nada) a 255 (máximo). Mueve los controles.

Prueba: 255, 0, 0 es rojo; 0, 0, 0 es negro; 255, 255, 255 es blanco. En hexadecimal, cada par de cifras (00–FF) es un componente.

HSL: elegir un color como lo pensamos las personas

170°
60%
30%
  • Tono (Hue): de 0 a 360, el giro por la rueda de colores. 0 = rojo, 120 = verde, 240 = azul.
  • Saturación: de 0 a 100 %. Cuanto más alta, más intenso. Con 0 %, gris.
  • Luminosidad: de 0 a 100 %. Con 0 %, negro; con 100 %, blanco.
  • HSLA añade un cuarto valor, la transparencia (0 a 1).

Ventaja de HSL: para un tono más oscuro del mismo color solo cambias la luminosidad, sin recalcular tres números.

Usar bien el color

  • Que los colores sean coherentes con la imagen de marca (branding).
  • Usa una única gama cromática.
  • Apóyate en la teoría del color: colores monocromáticos, complementarios o análogos.
  • Decide qué efecto quieres conseguir y hasta dónde jugar con el color.
  • Comprueba que haya buen contraste entre texto y fondo para que se pueda leer.

Estilo de los enlaces

Los enlaces cambian según su estado, y cada estado tiene su pseudo-clase.

Pseudo-claseEstado
a:linkEnlace no visitado
a:visitedEnlace ya visitado
a:hover *Ratón encima, sin clic
a:active *Mientras se hace clic
a:focus *Tiene el foco (por ejemplo, con Tab)

* Valen también para otros elementos HTML, no solo para enlaces.

Pruébalo (ratón, clic y Tab) Ver la carta de cafés

El orden importa: a:hover debe ir después de a:link y a:visited, y a:active después de a:hover. Recuerda LoVe HAte: Link, Visited, Hover, Active.

Resumen

Unidades

Absolutas (px, cm, pt) y relativas (em, rem, %, vw, vh).

Colores

Nombre, #RRGGBB, rgb()/rgba() y hsl()/hsla().

Texto

font-family, font-size, font-weight, text-align, line-height, text-shadow...

Enlaces

Pseudo-clases en orden: link, visited, hover, active (LoVe HAte).

Listas

list-style-type y list-style-image.

Tablas

border-collapse, border-spacing, caption-side, empty-cells, table-layout.

Autoevaluación: ¿lo tienes claro?

Contesta mentalmente y luego despliega cada pregunta.

1. ¿Qué unidad es relativa al tamaño de letra de la raíz del documento?

rem. La em es relativa al tamaño de letra del propio elemento.

2. Escribe el rojo puro de tres formas.

red, #FF0000, rgb(255, 0, 0) (también hsl(0, 100%, 50%)).

3. ¿Qué es el canal alfa en rgba()?

La transparencia: de 0 (invisible) a 1 (opaco).

4. ¿Para qué sirve text-align y qué valores tiene?

Para alinear el texto dentro de su contenedor: left, center, right, justify.

5. ¿Qué hace border-collapse: collapse en una tabla?

Une los bordes de celdas contiguas en uno solo.

6. ¿Por qué conviene terminar font-family con una familia genérica?

Porque, si el equipo no tiene las fuentes anteriores, el navegador usará una de esa familia (por ejemplo sans-serif).
