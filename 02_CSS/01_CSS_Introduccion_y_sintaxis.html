Sección 1

Introducción: qué es CSS y por qué existe

Antes de escribir código, entendamos el problema que resuelve.

El mismo HTML puede verse de formas muy distintas

Esta es una carta de cafetería escrita solo con HTML. Pulsa el botón: el HTML no cambia, solo añadimos CSS.

HTML dice qué hay en la página (un título, tres párrafos). CSS decide cómo se ve (colores, letras, espacios).

Cada lenguaje tiene su trabajo

HTML

¿Qué es esto? Describe el contenido y su significado: «esto es un título», «esto es una lista», «esto es un enlace».

Es un lenguaje de marcas y semántico: da sentido a la información (también para los buscadores).

CSS

¿Cómo se ve? Define colores, tipos de letra, tamaños, márgenes y posiciones.

No es un lenguaje de marcas: es un lenguaje de presentación, con su propia sintaxis.

Idea clave: separar contenido (HTML) y aspecto (CSS). Es como escribir un texto en un procesador de textos y aplicarle después un «estilo» sin tener que reescribirlo.

Cómo se hacía antes de CSS

Al principio, el formato se escribía dentro del propio HTML, con etiquetas como <font>:

El problema: cada vez que añadías un producto o cambiabas el estilo, había que repetir y modificar la etiqueta en cada elemento. Con 200 productos, 200 cambios.

La solución: definir el estilo una sola vez y que se aplique a todos los elementos que queramos. Eso es CSS. Hoy <font> está obsoleta.

¿Por qué no usamos solo HTML para dar formato?

  • Reutilizar. Un formato escrito aparte sirve para muchas páginas y mantiene un aspecto coherente en todo el sitio.
  • Significado. HTML es semántico: el contenido es de más calidad para buscadores y otras herramientas si no se mezcla con el aspecto.
  • Orden. Si el formato viviera en HTML, habría un montón de etiquetas, y cada navegador inventaría las suyas (ya ocurrió durante años).
  • Separar. Contenido y formato en sitios distintos: puedes cambiar el diseño sin tocar el contenido.
  • Control. Con solo HTML decide el navegador: tipo de letra, colores, tamaños, espacios... Cada uno tiene pequeñas diferencias. CSS da un aspecto más preciso en todos.

¿Qué es CSS?

Cascading Style Sheets
Hojas de estilo en cascada

Es el lenguaje que se inserta en las páginas web para definir su formato. Actúa sobre los elementos HTML y dice cómo se visualizarán en pantalla (u otros dispositivos).

  • Puede aplicarse a todas las etiquetas de un tipo o solo a algunas.
  • Puede guardarse en otro archivo y usarse en varias páginas a la vez.
  • También se puede aplicar a XML.

Ventajas

  • Presentación atractiva y coherente en todo el sitio.
  • Mantenimiento sencillo: cambias un archivo y se actualizan todas las páginas.
  • Reutilización: un estilo común para muchas páginas.
  • Menos código que escribir y más fácil de leer.

Versiones de CSS

CSS3 no es un único documento, sino una colección de módulos que evolucionan por separado. Ya no se publican versiones globales («CSS4» no existe): cada módulo avanza con su propio nivel y los navegadores van incorporando sus novedades.

Compatibilidad entre navegadores

No todos los navegadores soportan lo mismo a la vez. Puedes comprobarlo en:

  • caniuse.com
  • css3test.com

Cuando un navegador estrena una propiedad que aún no es estándar, la escribe con un prefijo:

PrefijoNavegadores
-moz-Firefox (motor Mozilla)
-webkit-Safari, Chrome (motor WebKit)
-ms-Internet Explorer (Microsoft), retirado en 2022
-a-Opera (desde 2013 usa WebKit)

Hoy los navegadores modernos necesitan muy pocos prefijos (herramientas como Autoprefixer los añaden solas). Pero los verás en código antiguo, así que conviene reconocerlos. Escribe siempre al final la versión sin prefijo.

Sección 2

Sintaxis: cómo se escribe CSS y cómo se añade al HTML

Una regla, tres formas de usarla.

Anatomía de una regla CSS

Selector: a qué elementos HTML se aplica (aquí, a todos los <p>).

Propiedad: qué característica queremos cambiar (color, font-size...).

Valor: el nuevo ajuste de esa característica (brown, 14px).

Comentarios

Son notas para las personas. El navegador las ignora. Empiezan con /* y terminan con */.

Las declaraciones de una misma regla también se pueden juntar: varias propiedad: valor; entre las mismas llaves.

Hay tres formas de añadir CSS a un HTML

FormaDónde se escribeCuándo usarla
Inline (en línea)En el atributo style del propio elementoCasi nunca. Solo si un único elemento necesita un estilo muy especial.
InternoDentro de <style>, en el <head>Cuando hay muy pocos estilos o la página es única.
ExternoEn un archivo .css enlazado con <link>La opción recomendada: un archivo para todas las páginas.

Las tres usan la misma sintaxis de reglas. Lo único que cambia es dónde escribes el CSS.

1. CSS inline (en línea)

El CSS se escribe en el atributo style del elemento. Aquí no hay selector: el estilo afecta solo a ese elemento.

Resultado
Cafés
Café Americano - 1.60 €

Por qué se evita: mezcla contenido y formato (justo lo que queríamos separar) y obliga a repetir el estilo en cada elemento.

2. CSS interno

Las reglas se escriben dentro de la etiqueta <style>, que va en el <head>.

Ahora el estilo se define una vez y vale para todos los <h1> y <p> de esa página.

Limitación: el estilo solo sirve para ese archivo HTML. Si tienes 20 páginas, tendrías que copiarlo 20 veces.

3. CSS externo (la forma recomendada)

Los estilos viven en un archivo .css y cada página lo enlaza con <link> dentro del <head>.

AtributoPara qué sirve
relTipo de relación con el documento. Siempre stylesheet.
typeTipo de recurso (text/css). Es opcional en HTML5: hoy se omite.
hrefRuta relativa o URL del archivo .css.
mediaMedio donde se aplica: all, print, screen, speech.

Puedes enlazar varias hojas repitiendo la etiqueta <link>.

Resumen

CSS

Lenguaje de presentación: separa el aspecto (CSS) del contenido (HTML).

Regla

selector { propiedad: valor; }. Cada declaración termina en ;.

Tres formas

Inline (style), interno (<style>) y externo (<link>, la recomendada).

Comentarios

/* ... */: el navegador los ignora.

Agrupar

h1, h2, p { ... } evita repetir declaraciones.

Orden

Organiza el CSS (por función o según el HTML) y coméntalo.

Autoevaluación: ¿lo tienes claro?

Contesta mentalmente y luego despliega cada pregunta.

1. ¿Qué significa CSS y para qué sirve?

Cascading Style Sheets. Define el aspecto y el formato de un documento HTML, separándolo del contenido.

2. Nombra las partes de p { color: red; }.

p es el selector; { color: red; } la declaración; color la propiedad y red el valor.

3. ¿Qué forma de añadir CSS es la más recomendable y por qué?

El CSS externo: un archivo reutilizable en todas las páginas, que mantiene el HTML limpio y facilita el mantenimiento.

4. ¿Qué atributos lleva <link> para enlazar una hoja de estilos?

rel="stylesheet" y href="ruta/archivo.css". El type y el media son opcionales.

5. ¿Cómo se escribe un comentario en CSS?

Entre /* y */. No existe // ni <!-- --> en CSS.

6. ¿Por qué ya no se usa <font>?

Mezcla contenido y formato, obliga a repetir el estilo en cada elemento y está obsoleta en HTML5.
