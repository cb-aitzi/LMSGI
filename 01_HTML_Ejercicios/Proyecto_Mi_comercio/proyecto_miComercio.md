# Proyecto: Creación de una Página Web

Deberás desarrollar una **página web completa utilizando HTML**, aplicando los conocimientos adquiridos durante las primeras unidades del módulo.

El tema de la página será **libre**. Puedes elegir el tipo de página que quierass, siempre que tenga suficiente contenido para poder aplicar los diferentes elementos HTML trabajados.

Algunas posibilidades son: una cafetería o restaurante, una tienda de ropa, deportiva o informática, un grupo musical, una asociación, o cualquier otra propuesta relacionada con vuestros intereses.

El objetivo principal de la actividad es **poner en práctica de forma conjunta todos los contenidos HTML trabajados hasta el momento**.

> **Importante:** en esta actividad no es necesario centrarse en el diseño visual de la página. Lo más importante es crear una estructura HTML correcta, organizada y coherente.



## Requisitos de la página web

La página deberá incluir, como mínimo, los siguientes elementos.

- **Estructura HTML:** El documento deberá utilizar una estructura HTML5 correcta. Deberán utilizarse, cuando tengan sentido dentro de la página, elementos semánticos como: `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<aside>` y `<footer>`. 

- **Formato de texto:** deberá contener diferentes elementos para organizar y dar formato al texto como `<h1>`, `<h2>`, `<h3>`, `<p>`, negritas y cursivas para organizar y destacar la información de la página.

- **Listas:** La página deberá incluir **al menos una lista ordenada y una lista no ordenada**, (`<ul>`, `<ol>`, `<li>`>) para mostrar menús de productos, listas de servicios, pasos para realizar una actividad, clasificaciones o características del negocio.

- **Tablas:** Se debe hacer uso de **al menos una tabla** (`<table>`) para organizar datos como una lista de precios, horarios de atención, información sobre diferentes servicios o una comparación de productos.

- **Enlaces:** Se debe incluir algún enlace (`<a>`) que dirija a otras secciones de la página o a sitios web relacionados con el negocio (como redes sociales o productos recomendados).

- **Multimedia:** Uso de imágenes (`<img>`) o videos (`<video>`) que complementen el contenido visual de la página, como fotos de productos, el local comercial, o videos promocionales.

- **Contenedores (`<div>` y `<span>`):** Se deben utilizar contenedores para organizar el diseño de la página, cómo `<div>` para agrupar secciones completas y `<span>` para resaltar elementos de texto.
